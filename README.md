# Video Restoration with Deep Learning
# Описание
Этот репозиторий содержит код модели и её обучения для задачи восстановления качества видео после сильного сжатия. Основная реализация находится в файле Network.ipynb, где:

Архитектура была взята из статьи [Deep Residual Autoencoder for quality independent JPEG restoration](https://arxiv.org/abs/1903.06117).

Проведено обучение модели на датасете который собрал я. 

Он был получен с помощью создания видео из кадров с использованием видеокодека VP8 (библиотека libvpx) в формате WebM. Также, был применён режим кодирования 'ultrafast'.
Это видео затем было декодировано до кадров. Полученные кадры использовались как входные данные для модели, а изначальные как целевые значения.
